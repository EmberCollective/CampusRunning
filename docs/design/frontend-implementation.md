# 工作台前端实现与验收

已按用户批准的 [HTML 草稿](frontend-draft.html) 接入现有前后端。生成记录、轨迹编辑和实验手表面板共用页面结构、样式与设置，未增加运行依赖。草稿文件保留为对照基准。

## 已接入的任务

| 任务 | 结果与恢复 |
|---|---|
| 生成记录 | 四种模式调用既有生成器；指定日期可跳转年月、跨月保留和移除日期；生成后可下载 FIT／TCX 或 ZIP |
| 参数模板 | 读取现有预设，导入、导出和缓存本地 JSON；兼容旧小时字段，保留指定日期 |
| 生成页地图预览 | 滚轮、触控缩放与缩放按钮；拖动平移，适配整条轨迹；单击地图或按回车进入所选轨迹的编辑器；后台刷新保留视野 |
| 轨迹编辑 | 真实地图、单点拖动、中点插入、画笔、擦除、框选、移动、八柄缩放、旋转、数值变换、撤销与重做 |
| 快捷图形 | 操场、矩形和圆形先预览再确认；取消恢复原选区；复用现有环线接入几何，重叠时拦截 |
| 轨迹保存 | 沿用 GCJ-02 与原保存接口；覆盖需确认；失败保留输入；切换轨迹保留本页编辑，离开提醒未保存内容 |
| 手表批次 | 生成 B5 不自动载入；用户在手表页显式载入后才调用既有同步接口；当前还有待接收文件时保护本批次 |
| 手表状态 | 读取真实接口；停止、启动未确认和读取失败时清空可填写地址，保留记录；文件接收与活动有效性分开 |
| 文件接收进度 | 标题栏展示已确认文件数／本批总数及百分比；筛选不改变进度，空批次隐藏；读取失败保留数值并标注“上次确认” |
| 设置 | 地图 Key 沿用本地保存接口；Netsim 使用启动配置；Windows 与其他兼容层提供可查看的配置位置，尚不能启用 |

旧的 `/`、`/track-editor?track=<id>`、`/watch` 入口继续有效。普通 Web 不显示手表入口或 B5 输出，也不加载实验手表脚本。以上整组改动包含私有功能，不可整线推送到公开仓库。

`/api/watch/status` 新增 `transport: "netsim"` 与 `binding_address: {value, medium: "virtual"}`。仅当前面板拥有的进程仍运行且已确认就绪时提供虚拟地址；其他情况 `value` 为 `null`。旧身份字段保留兼容，前端不使用它们替代当前可填写地址。此规则仅用于当前 Netsim 接入，不外推到实体广播。

## 与草稿的视觉对照

- `web/static/css/style.css` 与审批草稿样式内容相同；地图覆盖层等接入样式单独补充。
- 在 Chromium、相同示例数据下，对编辑器、生成、手表与设置各截图，覆盖 390×844、1024×768、1440×960、2560×1440，共 16 组。每个视口重新载入正式页面，等待地图缩放完成。
- 已比较导航、分栏、工具栏、画布、表格、底部操作和设置弹层的矩形位置与大小；所检查边界最大差异为 **0px**。
- 1440px 下，工具栏、快捷图形、选区属性和日历的截图裁片，逐像素差异均为 **0**。截图检查使用减少动态效果设置，避免按钮过渡色干扰。
- 已实际打开并人工审阅桌面、手机、宽屏对照图和真实在线地图截图；修复了预览 SVG 尺寸干扰、节点外观、手机端额外设置行、说明换行与宽屏旋转柄裁切。

这不代表整页所有像素相同。正式页面使用真实地图、投影与轨迹数据，缩放范围沿用地图引擎；草稿使用示意 SVG。正式文案表达实际保存和生成行为，移除了草稿专用的状态模拟下拉；未接入的传输配置禁用。地图内容、实际数据和这些必要状态差异不纳入裁片像素相等的结论。

后续按用户要求新增预览缩放控件和文件接收进度条，未修改审批草稿。进度条放在“本批运动记录”标题栏，390px 下独占一行，表格及外层容器相应增加约 33px；视觉回归单独断言这项预期增量，其他所检查边界仍为 0px 差异。已查看新控件和实际 16／16 接收状态的桌面、手机截图。

截图、轨迹、SPORT44、下载文件及状态均在仓库外的隔离目录；不提交这些运行资料。

## 使用与未验证范围

重启原有本地服务并刷新页面即可加载新版界面及地址状态字段。本次没有改动原服务的启动配置。

预览缩放和进度条这次增量由静态脚本创建控件，强制刷新即可加载。已在原 5000 服务只读确认缩放、点击进入编辑、进度 16／16 和无页面错误，原广播、连接与记录均保持。未重启广播，未替换批次。

实现阶段已读取代码和进行本地功能、安全复核，未进行外部独立审查或打包产物验收。本轮未重新验证实体蓝牙、Netsim 与 Keep 的真实连接／接收／活动入账，也未配置真实 Key 检查官方高德 JS 引擎与地点搜索。Windows 独立入口、iOS 和其他兼容环境的既有验收边界不变。
