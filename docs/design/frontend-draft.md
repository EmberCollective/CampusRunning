# CampusRunning 前端草稿

**审批用原型，不是正式前端实现。** 在仓库内直接用浏览器打开 [frontend-draft.html](frontend-draft.html)，无需启动服务。配套样式、交互脚本及仓库现有几何脚本须保持相对位置。

所有地址、运动记录、环境与地图均为示例。草稿不连接服务、不启动蓝牙、不请求地图、不读取本机配置、不写入轨迹库，也不生成运动文件。图形编辑与设置只保留在本页，刷新后恢复。

## 每块空间为什么存在

| 区域 | 布局与用途 | 不常驻的内容 |
|---|---|---|
| 全局导航 | 顶部 52px，仅三个任务入口和设置；不再占用整列侧栏 | 连接说明、地图设置、兼容说明在相关入口展开 |
| 生成设置 | 左栏 380px，宽屏 400px；依次选择轨迹、日期、里程、配速和输出，主要操作固定在底部 | 休息日、周末系数只在总公里数出现；文件目录只在文件输出出现 |
| 生成预览 | 常见窗口中地图在上、结果在下；宽屏把地图与结果并列，避免把四列表格拉满整个屏幕 | 结果未生成时保留有说明的结果区；不拿虚构数据填满空白 |
| 轨迹资源 | 左栏 216px，提供轨迹切换和操场／矩形／圆形快捷图形 | 图形参数与确认操作在放置时出现 |
| 轨迹画布 | 吃掉剩余空间；编辑工具靠近画布，地图搜索与底图选择靠近地图 | 专注模式可以收起两侧面板 |
| 属性 | 右栏 272px，放名称、ID、描述；选中后才显示变换参数 | 没有选区时不堆放失效的缩放／旋转按钮 |
| 手表控制 | 左栏连接与地址，右侧当前批次统计和文件表格；表格占据连续工作区 | 待载入的新批次只在用户从结果进入时出现 |
| 设置 | 集中容纳广播环境、适配范围与地图服务，避免打断日常生成和编辑 | 观察工具路径、业务身份等低频配置按需展开 |

桌面工作区占满视口，设置、属性和长表格各自滚动，主要操作保留在固定区域。窄屏按任务顺序排列，不通过整体缩小页面保留桌面三栏。

## 可以在草稿中检查

- **生成：**四种模式、范围校验、参数模板、结果预览、文件与手表两种后续入口。修改参数后，旧结果的后续操作失效，重新预览才恢复。
- **指定日期：**上月／下月、年月跳转、本月、跨月保留、已选日期移除、清空、键盘方向键移动。日历宽度受设置栏约束。
- **轨迹：**拖动画布／单点、画笔、擦除、线段中点插入、矩形框选、全选、移动、边柄／角柄缩放、旋转、数值变换、删除、撤销／重做、缩放、适配、清空确认、页面内轨迹切换及保存反馈。
- **快捷图形：**先放置，再调整和确认；取消不改原轨迹；追加复用原有环线接入几何，重叠时保留图形并提示移开。
- **手表：**等待、已连接、全部已接收、停止、空队列、读取失败、地址未知；筛选、复制、重试、显式载入和未完成批次保护。
- **广播与兼容：**Netsim、Windows 实体蓝牙、其他传输／兼容层的配置位置。切换路线前要求停止广播；尚未接入的路线不展示可启动状态。修改地图设置不打断广播。

地点搜索、在线底图、环境检测、文件导出、真实保存和真实同步只展示入口及边界。此处不提供兼容库隔离、重装、清空绑定等系统操作。

## UX 与视觉决定

1. **状态可见：**广播、连接、文件接收、活动有效性分开；停止或地址观察失效后清空本轮可填写地址。
2. **用户掌控：**生成不会同步，预览不会替换当前批次；草稿提供取消、撤销、恢复和有说明的重试。
3. **减少记忆：**跨月已选日期可见，切换模式与轨迹保留页面内输入，快捷键说明集中提供。
4. **错误预防：**无效区间、过期结果、空轨迹、未完成批次和未接入路线在下一步前拦住。
5. **渐进披露：**选区、图形确认与高级配置随上下文出现；避免重复的常驻卡片和说明区。

| 视觉层 | 草稿处理 |
|---|---|
| 间距 | 4px 节奏，分区内常用 12–20px；固定宽度表单，不让字段无限拉长 |
| 颜色 | 保留靛蓝强调色，灰白工作区；语义色仅表达状态 |
| 图标 | 同一线性图标语言，用文字和焦点补足含义 |
| 文案 | 面向生成、编辑、接收等具体动作；草稿反馈不冒充真实成功 |
| 字体 | 系统中文字体，数字等宽；以层级和对齐组织信息 |
| 布局 | 顶部任务导航、连续工作区、按对象组织的侧栏和固定状态栏 |
| 细节 | 主面板直边，输入／按钮 3–4px 小圆角；禁用、选中与键盘焦点各自可辨 |
| 视觉内容 | 地图、节点与路线承担内容，不增加装饰图片或大号手表摆件 |
| 动效 | 仅短暂颜色反馈，尊重减少动态效果设置；无循环或布局动画 |

## 参照与接入边界

核对了 [QGIS 官方界面说明源码](https://github.com/qgis/QGIS-Documentation/blob/master/docs/user_manual/introduction/qgis_gui.rst) 及该文引用的官方界面图：采用工具栏、资源面板、中央地图、属性与状态栏的任务组织，按本项目功能收减。QGIS 文档网页本次返回 403，改读其官方仓库源文件和配图；不把其他未访问成功的产品作为已验证依据。

另核对了 [Syncthing 官方界面说明](https://docs.syncthing.net/intro/gui.html) 中对本地数据、待同步数据与状态的区分，仅借鉴状态组织，不沿用其自动同步语义。

广播与适配按当前 [传输接口](../keep-b5/design/transport-interface.md) 和 [兼容范围](../keep-b5/reference/compatibility.md) 规划：当前面板直连 Netsim；Windows 独立入口尚未迁入面板，其他兼容环境未完成接入。预留配置不代表实现或验收完成。

原型复用 [图形几何](../../web/static/js/shape_geometry.js) 与 [选区变换](../../web/static/js/selection_geometry.js)，没有修改这些文件。画布使用示意平面；正式实现仍须沿用既有地图投影、GCJ-02 数据约定与后端校验。

设计过程参考 unslop by Damir Sokolovsky（[@heydamir](https://x.com/heydamir)），CC BY 4.0。

## 已做的草稿检查

浏览器内部检查共 98 项，包括生成与载入分离、跨月选择、参数变更、节点编辑与框选、模板确认／取消、撤销、文本框快捷键、长表格内部滚动、广播地址失效、兼容设置及对话框焦点。覆盖 320、360、390、600、760、800、1024、1200、1440、1920、2560px 宽度；无横向页面溢出，桌面工作区高度稳定，无外网请求或未捕获错误。

截图和检查记录存仓库外。以上只证明草稿中的布局和模拟交互，不证明正式生成器、地图服务、蓝牙或 Keep 可用；未进行真实用户测试。

用户已批准按此草稿实现。草稿 HTML、样式和脚本保留为视觉基准；正式接入与验收范围见 [前端实现记录](frontend-implementation.md)。
